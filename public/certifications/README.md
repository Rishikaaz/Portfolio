- `cisco.png` (or `.jpg`) - Networking Basics & Cyber Threat Management
- `coursera.png` (or `.jpg`) - The Bits and Bytes of Computer Networking
- `aws.png` (or `.jpg`) - AWS Cloud Practitioner & AWS Skill Builder
- `deloitte.png` (or `.jpg`) - Cybersecurity Job Simulation
